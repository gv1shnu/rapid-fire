How play works

  • Each student gets one attempt per round. Reconnecting resumes the same attempt; it never grants a second one or more time.
  • The instructor selects the question count and seconds per question. Each question has its own server deadline. Unanswered questions time out, including while disconnected. The joining window lasts the nominal question count multiplied by seconds per question; closing that window does not shorten an attempt already in progress. The instructor can end the release early, and the session has a separate hard closing time. Remaining unanswered questions then receive zero points.
  • Scores, correct answers and explanations are revealed only at the debrief after a round closes. Wrong answers carry no negative points.
